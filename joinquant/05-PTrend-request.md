从基本面的角度来说
用趋势策略，针对上面切片时间段，进行回测，看资金曲线和进出场点

| 策略要求            |       |
|---------------------|-------|
| 回测本金            | 100万 |
| 资金使用率（仓位）  | 10%   |
| 当天最大回撤        | < 5%  |
| 1周或10日内最大回撤 | < 10% |

每一个切片按照100万本金，10%的仓位，比如10万用足了，去回测每个时间切片，提供单独的资金曲线。
如10万除以棕榈油价格，假设11.8手，四舍五入取下，可做11手。

如果有现成的趋势策略，可以针对给的时间切片，做回测，再针对提供的时间切片做优化，看优化后的效果。
